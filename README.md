# Backend Project (Chai aur Code)

This is a comprehensive backend project built by following the complete backend development series from the [Chai aur Code](https://youtube.com/playlist?list=PLu71SKxNbfoBGh_8p_NS-ZAh6v7HhYqHW&si=smQV_Qmqj8ZepzIf) YouTube channel. 

I have learned a tremendous amount about backend architecture, industry-standard practices, routing, middleware, database modeling, authentication, and more while building this project!

## 🚀 Tech Stack

- **Runtime Environment:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **ODM (Object Data Modeling):** Mongoose
- **Authentication & Security:** 
  - JSON Web Tokens (JWT) for secure authentication
  - bcrypt for password hashing
- **File Uploads:** Multer & Cloudinary
- **Other Utilities:** 
  - `cookie-parser` for handling cookies securely
  - `cors` for Cross-Origin Resource Sharing
  - `dotenv` for managing environment variables

## 📚 What I Learned

Throughout this project, I gained hands-on experience with:
- Setting up a robust and scalable Node.js/Express application.
- Building RESTful APIs with proper routing and controllers.
- Connecting to MongoDB and designing schemas/models using Mongoose.
- Writing complex aggregation pipelines in MongoDB.
- Implementing secure user authentication and authorization.
- Handling file uploads efficiently using Multer and storing them on Cloudinary.
- Managing errors effectively using custom error handling middlewares.
- Best practices for project structure and clean code.
